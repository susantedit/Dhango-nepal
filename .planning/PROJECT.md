# Project Vision: Dhango Nepal

- **Name:** Dhango Nepal
- **Domain:** Custom T-Shirt Printing E-Commerce Platform
- **Location:** Kathmandu, Nepal (serving all provinces)
- **Tech Stack:** MERN (MongoDB, Express, React, Node.js) + Three.js + MediaPipe Pose + Tailwind CSS
- **Core Value:** Premium custom t-shirt design studio in 3D, zero-cost real-time virtual try-on, and simple manual QR checkout at Rs. 1,500.

## Success Criteria
1. Zero external GPU/AI API cost for 3D customization and virtual try-on.
2. Fully responsive mobile and desktop storefront with Emil Kowalski design polish.
3. Clean order submission with manual QR payment screenshot upload.
4. Protected admin dashboard to inspect uploaded artwork and verify payment slips.
5. High-ranking SEO architecture with Nepal local schema and GEO tags.
