# Roadmap & Phase Progression: Dhango Nepal

- **Phase 1: Foundation & Backend Architecture (Tasks 1–9)**
  - Workspace scaffolding, Express server, MongoDB schema, Multer file upload handlers, Products & Orders REST APIs, Admin API.
- **Phase 2: Frontend Scaffolding, Design System & Storefront (Tasks 10–16)**
  - Vite React setup, Emil Kowalski design tokens, Navbar, Hero with strikethrough pricing (Rs. 1,500), Trust badges, Product catalog, Homepage customizer teaser.
- **Phase 3: 3D Customizer Studio Engine (Tasks 17–21)**
  - Three.js 360° viewport, Garment color switcher, Drag-drop graphic transform engine, Typography & Clipart tools, High-res 300 DPI print export.
- **Phase 4: Real-Time Virtual Try-On Suite (Tasks 22–24)**
  - Studio model wrinkle displacement engine, User photo upload try-on, Browser-based webcam pose mirror ($0 API cost).
- **Phase 5: Cart, Checkout & Manual QR Payment Flow (Tasks 25–29)**
  - Cart state drawer, Nepal checkout form, Manual QR display & slip screenshot uploader, Congratulations screen with WhatsApp link, Public order tracking portal.
- **Phase 6: Admin Dashboard & Order Management (Tasks 30–31)**
  - Protected admin panel, KPI metrics, Artwork download, Payment receipt inspect modal & status workflow.
- **Phase 7: SEO, Local GEO & E2E Playwright Verification (Tasks 32–33)**
  - JSON-LD Nepal schema, Sitemap, Robots, Meta tags, Automated Playwright testing across devices.
